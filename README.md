# Flutter JSON Data

This repository contains JSON files hosted online for use in Flutter applications.

## Purpose

The purpose of this repository is to store and provide JSON data online for Flutter applications. It allows developers to access JSON files remotely through their URLs, making it easier to practise fetching data from the internet, decoding JSON responses, and using the retrieved data within Flutter applications. It also serves as a simple resource for learning how to work with remote data and integrate it into Flutter projects.

## Files

- person.json – Contains sample person information.

## Usage

JSON files can be accessed directly using their Raw GitHub URLs.

Example:

https://raw.githubusercontent.com/USERNAME/flutter-json-data/main/person.json

## Technologies

- JSON
- GitHub
- Flutter
- Dart

## Note

This repository is intended for learning and testing purposes. It does not provide a database or dynamic data management.
