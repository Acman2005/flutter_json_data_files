# Flutter JSON Data

This repository contains JSON files hosted online for use in Flutter applications.

## Purpose

The purpose of this repository is to provide remotely accessible JSON data for learning and practising data fetching, JSON parsing, and API integration in Flutter.

## Files

- person.json – Contains sample person information.

## Usage

JSON files can be accessed directly using their Raw GitHub URLs.

Example:

https://raw.githubusercontent.com/USERNAME/flutter-json-data/main/person.json

## Technologies

- JSON
- GitHub
- Flutter
- Dart

## Note

This repository is intended for learning and testing purposes. It does not provide a database or dynamic data management.
